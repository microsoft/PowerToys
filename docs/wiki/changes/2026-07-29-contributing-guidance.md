# Adopt PowerToys contribution workflow

**Date:** 2026-07-29

## Decision

Apply the PowerToys contributor workflow to this repository: issue first, discuss the problem and approach, require an agreed spec for larger changes, keep branches and pull requests atomic, and document local build and test validation.

## Repository changes

- Expanded `CONTRIBUTING.md` with the repository-specific workflow and links to developer documentation and the wiki index.
- Updated `.github/pull_request_template.md` to prompt for issue/scope agreement, atomicity, build and test evidence, skipped validation, and wiki logging.
- Added this indexed change log under `docs/wiki/`.
